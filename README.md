# Cologuri Server (কোলোগুড়ি ব্যাকএন্ড এপিআই)

Node.js, Express, MongoDB, এবং Socket.io চালিত ব্যাকএন্ড এপিআই এবং রিয়েল-টাইম সিট লকিং সার্ভিস।

## বৈশিষ্ট্যসমূহ (Features)
- **ট্যুর ও বুকিং ম্যানেজমেন্ট**: ট্যুর লিস্ট, ফিল্টারিং এবং বুকিং লাইফসাইকেল।
- **রিয়েল-টাইম সিট লকিং (Socket.io)**: একাধিক ব্যবহারকারী একই সাথে বুকিং করলে রেস-কন্ডিশন প্রতিরোধ ও তাৎক্ষণিক সিট আপডেট।
- **অথেনটিকেশন**: JWT ভিত্তিক অ্যাডমিন ও ইউজার সাইনইন।
- **নোটিফিকেশন সার্ভিস**: বুকিং আপডেট ও এসএমএস/ইন-অ্যাপ নোটিফিকেশন।

## সেটআপ ও রান করার নিয়ম (Setup & Run)

```bash
# ১. ডিপেন্ডেন্সি ইনস্টল
npm install

# ২. এনভায়রনমেন্ট কনফিগারেশন
cp .env.example .env
# .env ফাইলে MongoDB URI ও JWT_SECRET ঠিক করুন

# ৩. ডেভেলপমেন্ট সার্ভার চালু
npm run dev

# ৪. প্রোডাকশন সার্ভার চালু
npm start
```

## এপিআই এন্ডপয়েন্ট (API Endpoints)
- `GET /api/health` — হেলথ চেক
- `GET /api/tours` — সকল ট্যুর প্যাকেজ
- `GET /api/tours/:id` — নির্দিষ্ট ট্যুর বিস্তারিত
- `POST /api/bookings` — নতুন সিট বুকিং
- `POST /api/auth/login` — ইউজার ও অ্যাডমিন লগইন
